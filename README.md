# Ugh Xcode releases

Ugh Xcode is a macOS menu bar app that shows how much disk space Xcode and its simulators use, and permanently deletes the items you check.

- **Download:** the latest signed and notarized DMG is on the [Releases](https://github.com/jinahadam/ugh-xcode-releases/releases) page.
- **Updates:** the app checks `https://raw.githubusercontent.com/jinahadam/ugh-xcode-releases/main/appcast.xml` with Sparkle. Each release commits a new `appcast.xml` to `main`.

Requires macOS 26 or later.
